FOC 上位机

Web Serial · STM32G431 USART1 · 115200/8N1 未连接

① 连接串口

需用 Chrome / Edge 打开本页（Web Serial 仅 Chromium 支持）。
连接后选对 MCU 的 COM 口。

② 运行控制

⚠ 点 Enable 会真正给电机上电并转动，务必确认机械安全！
发 stop→disable→reset，真重启 MCU 并清空波形

③ 命令输入

回车 = 发送并追加 \n。命令见下方协议。
通信协议（来自固件 comm_host.c）
命令(换行结束): mode idle|pos|spd|cur target <值> # 按当前模式设目标 pid <环> <kp> <ki> [kd] # 环:0位置 1速度 2=id 3=iq enable / disable / stop / reset monitor [pos spd iq id vbus] # 无参=切换开关 status / encoder / help 回传: OK: ... / ERR: ... STATUS: mode=.. en=.. state=.. fault=.. vbus=.. pos=.. spd=.. id=.. iq=.. # 结构化状态(上位机⑥卡片解析) 上电横幅: 每次复位/上电自动打印一行 STATUS: + "FOC ready" 提示 监视流: t=<秒>, spd=.. iq=.. id=.. vbus=.. 调试CSV(200Hz): pos,tpos,spd,tspd,iq,tiq,id,vq

④ 实时波形

X 轴 = 采样序号（左进右出），每信号独立自动量程，虚线=0。

⑤ 实时读数

⑥ 电机状态

模式 — 断电 状态 — 无故障
上电横幅 / 连接后自动刷新；也可点 ② 区 status 按钮手动刷新。
